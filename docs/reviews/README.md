# Review Artifacts

This folder stores external review inputs and reference artifacts that informed implementation decisions.

Rules:

- Distill accepted requirements into `AGENTS.md`, which remains the project source of truth.
- Keep original review artifacts here when they are useful for auditability or future comparison.
- Do not import files from this folder into runtime application code.
